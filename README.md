Digital Wedding Invitation

Static digital wedding invitation

## Preview Locally

```bash
npm run start
```

## Check

```bash
npm run check
```

## Structure

- `index.html` - GitHub Pages entry page
- `assets/css/styles.css` - visual system and responsive layout
- `assets/js/script.js` - countdown, invitation gate, photo slider, wish form, gift reveal, and navigation state
- `PRODUCT.md` - product context
- `DESIGN.md` - design system notes
